에린 악보 공방 — 초보자용 실행 안내

[현재 버전에서 가능한 것]
- MIDI(.mid/.midi) 파일 브라우저 내 불러오기 및 간단한 MML 초안 생성
- 최대 6개 트랙을 파트로 변환
- 파트별 MML 직접 편집, 글자 수(2,400자) 표시
- 악보를 브라우저 보관함에 저장/검색/열기/삭제
- 전체 복사 및 TXT 내보내기
- YouTube URL 영상 미리보기

[실행 방법]
1. index.html 파일을 다운로드합니다.
2. 파일을 더블클릭하면 Chrome/Edge에서 열립니다.
3. MIDI 파일을 선택한 뒤 'MML 변환하기'를 누릅니다.
4. 생성된 파트를 검토/수정하고 '악보 보관함에 저장' 또는 '.txt로 내보내기'를 누릅니다.

[중요한 제한]
- 이 파일은 초보자가 바로 테스트할 수 있는 프로토타입입니다. MIDI 이벤트를 바탕으로 단순한 MML 초안을 생성하며, 모든 곡의 정확한 리듬/화음/게임 호환성을 보장하지 않습니다.
- 변환은 트랙의 음표를 시간순으로 단순화합니다. 복잡한 동시 화음은 음악적으로 완벽하게 분리되지 않을 수 있습니다.
- YouTube 링크 기능은 영상 미리보기만 합니다. URL만으로 오디오를 추출하거나 자동 채보하지 않습니다.
- 악보 보관함은 현재 브라우저의 localStorage에 저장되므로 다른 기기와 동기화되지 않습니다. 중요한 악보는 TXT로 내보내세요.
- 공개 배포 시에는 HTTPS로 호스팅하는 것을 권장합니다. index.html은 정적 사이트 호스팅(GitHub Pages 등)에 올릴 수 있습니다.

[다음 개발 단계 권장]
1. 변환 결과를 실제 마비노기 모바일에서 검증하고 MML 문법/음역/쉼표 처리를 보정합니다.
2. 화음 자동 분리와 2,400자 초과 시 구간 나누기 기능을 개선합니다.
3. YouTube 자동 음정 분석은 사용 권한이 있는 오디오 파일 기반 분석 또는 적법한 외부 분석 서버를 별도로 설계해야 합니다.
4. 여러 사용자가 악보를 공유하는 공개 자료실에는 데이터베이스/백엔드가 필요합니다.
